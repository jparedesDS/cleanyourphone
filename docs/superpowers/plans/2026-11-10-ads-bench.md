# Ads and Proof Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Private DNS ad-block presets/checks and a local before/after benchmark to the CLI, then expose both in the Windows app.

**Architecture:** The CLI owns two new capabilities: `dns providers/check` (on top of the existing journaled `dns set`) and `bench snapshot/compare` (local JSON and Markdown). The app calls those commands through `CliClient`, adds an optional ads card to Review, and takes automatic before/after snapshots around Apply.

**Tech Stack:** Python 3.10+ stdlib CLI, unittest, PySide6 app, pytest/pytest-qt, PyInstaller/Inno Setup.

**Spec:** `docs/superpowers/specs/2026-11-10-ads-bench-design.md`

## Global Constraints

- No uninstall, suspend, root, ROM, Shizuku or new package-removal path.
- No “60% more RAM”, “2x faster” or causal performance claims.
- DNS changes remain journaled; `restore` restores the previous Private DNS state.
- Bench files are local and contain model/build but no serial, IMEI, IP or account data.
- `dns check` must say “cannot test” when the control domain fails, not “blocked”.
- CLI version becomes `0.3.0`; app sidecar pins `v0.3.0`; app version stays `0.1.0`.
- The app release remains blocked on a real supported-phone test.
- Windows app: Windows 10/11 x64, Python 3.12, PySide6 6.8+.

## Review Focus

- A router/VPN already blocks DNS: `dns check` must distinguish “blocked” from “offline/cannot test”.
- A user turns ads on and later runs `restore`: the previous DNS mode/specifier must come back.
- Bench snapshots are compared after a reboot or with Battery Saver on: the report must warn, not claim.
- The app applies packages successfully but DNS or bench fails: the package result must remain valid and the failure visible.
- The app is in English: Spanish package translations must not leak into English (existing rule).

```python
def _resolve(serial: str, host: str) -> str:
    try:
        out = adb.shell(f"ping -c 1 -W 3 {host}", serial=serial, timeout=20)
    except adb.AdbError:
        return ""
    match = re.search(r"PING \S+ \(([^)]+)\)", out)
    return match.group(1) if match else ""

def dns_check(serial: str) -> dict:
    ad_ip = _resolve(serial, "doubleclick.net")
    control_ip = _resolve(serial, "wikipedia.org")
    online = control_ip not in ("", "0.0.0.0", "::")
    if not online:
        blocked = None
    else:
        blocked = ad_ip in ("", "0.0.0.0", "::")
    return {
        "ad_domain": "doubleclick.net",
        "ad_ip": ad_ip,
        "ad_blocked": blocked,
        "control_domain": "wikipedia.org",
        "control_ip": control_ip,
        "online": online,
    }
```

`cmd_dns` accepts `providers` (table/JSON), `check` (JSON/table, exit 0 only when `ad_blocked is True and online`), and `set` resolves a preset alias before validating the hostname. Keep `off` and `restore` unchanged.
